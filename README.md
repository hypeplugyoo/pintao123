# Consórcio CRM 🚀

CRM SaaS focado em operações comerciais de consórcio.

## Objetivo
Centralizar leads, clientes, oportunidades, follow-ups, propostas e indicadores para aumentar a produtividade do time comercial.

## MVP
- Dashboard comercial
- Leads e clientes
- Pipeline Kanban
- Cadastro de oportunidades
- Follow-ups e tarefas
- Histórico de interações
- Produtos e cotas de consórcio
- Propostas e vendas
- Métricas de conversão
- Gestão de vendedores

## Arquitetura planejada
Frontend web responsivo + API + PostgreSQL + autenticação + arquitetura multi-tenant.

## Status
🚧 MVP em desenvolvimento
